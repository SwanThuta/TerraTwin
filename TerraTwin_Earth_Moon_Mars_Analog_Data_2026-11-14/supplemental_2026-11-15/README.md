# Supplied regional measurements (2026-11-15)

These five CSV files are byte-for-byte copies from the user-supplied `data.zip`. They are kept together so the numerical values, units, methods, missing cells and quality notes stay traceable. `terratwin_master_dataset.csv` is the 14-location combined table; the Earth, Mars and Moon files retain more extraction detail. `terratwin_similarity_rankings.csv` is an experimental slope-only result, not the app's terrain/geology ranking.

The import is **regional context, not reviewed feature evidence**. Existing `locations.csv` IDs name narrower features or image scenes, while the imported IDs name broad locations, craters or raster windows. For example, `EARTH_02` covers Haughton broadly rather than Locale 7 (`E01`); `MOON_001` covers a south-polar raster rather than the selected Shackleton image (`L01`); `MARS_001` covers a 20 km Jezero window rather than the carbonate margin (`M01`) or delta (`M02`); `MARS_002` covers a Gale window rather than a selected ancient lake deposit (`M04`). The Nobile Rim 1 raster is not the Marius Hills Pit (`L02`). These are geographic associations, not measurement joins.

The supplied lunar CSV contains projected raster bounds and no angular latitude/longitude for its targets. The planetary globe pins instead use the independently cited coordinates already in `locations.csv`. L01/L02 show source-located image/pit points; M01–M04 show labeled regional context anchors. Planetary source longitudes are positive East 0–360 degrees and are converted to signed East -180–180 degrees only for globe display.

No values from these files have been copied into `metric_measurements_template.csv`, the scored pair tables, or the generated comparison PDFs. The feature footprints, comparable processing and source-product validation required for those uses are still outstanding. Keep blanks as missing; inspect the Earth zero values and the lunar nodata mask before quantitative use. The slope-only similarity values must not replace the fixed qualitative rubric or be presented as verified percentages.
