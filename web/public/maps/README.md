# Earth locator land layer

`ne_110m_land.geojson` is the Natural Earth 1:110m land layer from the [Natural Earth vector repository](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson), retrieved 2026-11-14. [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/) state that its map data are public domain. The map displays “Made with Natural Earth” attribution.

This generalized coastline is only orientation context. TerraTwin's markers are separately sourced regional points and do not indicate feature boundaries, access routes, or exact observation locations.
