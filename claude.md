# Claude project instructions

Read and follow [agents.md](agents.md) for the shared coding rules. Then read [spec.md](spec.md), [design.md](design.md), and [todo.md](todo.md). Explicit user instructions take precedence.

The shared instructions are authoritative for this repository; do not duplicate them into a separate, conflicting policy.

For each task:

1. Inspect the current implementation and relevant task ownership.
2. Implement the smallest complete change that satisfies the specification.
3. Explain the change briefly for beginner-to-intermediate developers.
4. Verify the affected behavior and report actual results.
5. Update documentation and task status when warranted.

Scientific results must remain sourced, reproducible, and honest about missing evidence. Explanations use structured evidence templates until an API is connected later. Preserve the scope of a little-over-24-hour hackathon.

This filename uses the requested lowercase spelling. If the Claude tool requires `CLAUDE.md` on a case-sensitive system, rename this entry file to the expected casing or configure it to load this file explicitly. Keep one authoritative shared instruction source in `agents.md`.
